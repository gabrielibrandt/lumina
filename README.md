# ✨ Lumina

Lumina é um projeto de site de roupas desenvolvido como protótipo de front-end para apresentação acadêmica na disciplina **Competências Digitais e Tecnologias Aplicadas à Gestão**.

O projeto foi criado com o auxílio do Antigravity e teve como principal objetivo demonstrar a importância da prototipação no desenvolvimento de sistemas e produtos digitais.

A proposta consistiu em apresentar para um cliente imaginário uma primeira versão visual do site antes do desenvolvimento completo da aplicação.

---

# 🎯 Objetivo do Projeto

O Lumina foi desenvolvido para simular a etapa inicial de criação de um produto digital voltado para o setor de moda.

O foco principal do projeto foi:

* Demonstrar uma proposta visual de front-end
* Simular a apresentação de um projeto para um cliente
* Validar ideias antes do desenvolvimento completo
* Destacar a importância da prototipação
* Mostrar como alinhamento visual reduz retrabalho

O projeto representa uma primeira versão conceitual da interface de um e-commerce de roupas.

---

# 🧠 Importância da Prototipação

Antes de iniciar o desenvolvimento completo de um sistema, é essencial que exista clareza sobre:

* O que o cliente deseja
* Como a interface será estruturada
* Qual será a identidade visual do projeto
* Como os usuários irão interagir com o sistema

O Lumina foi criado justamente para representar essa etapa inicial de validação.

A prototipação ajuda a:

* Reduzir erros no desenvolvimento
* Evitar retrabalho
* Melhorar a comunicação com o cliente
* Tornar o processo mais eficiente
* Facilitar futuras implementações

# 💻 Como Executar o Projeto

## 1. Clone o repositório

```bash
git clone https://github.com/gabrielibrandt/lumina.git
```

## 2. Acesse a pasta do projeto

```bash
cd lumina
```

## 3. Abra o arquivo `index.html`

Você pode abrir diretamente no navegador ou utilizar extensões como:

* Live Server (VS Code)

## 4. Ou então é possível acessar o site que está no ar com o GitHub Pages

https://gabrielibrandt.github.io/lumina/
